Rules resolve, but some sources/targets are unusable on disk.

Try:
  dots doctor           exit 1: "! error" for each bad entry, the rest listed
  dots apply            refuses to start; ~/.vimrc and ~/.config/nvim are NOT
                        created even though they are fine
  dots apply --dry-run  same errors

Expect errors for:
  ~/.missing            source does not exist
  ~/.broken             source symlink is broken
  ~/.fifo-source        source is a FIFO
  ~/.blocker/child      parent is a regular file
  ~/.linkdir/child      parent is a symlink
  ~/.fifo-target        target is a FIFO (cannot be backed up)
  repo/vimrc-self       target is the source itself
  repo/nvim/inner       target inside source
  repo/pack             target contains source
